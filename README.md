# 安護交班｜居家服務交班平台

獨立研究專案：`BiuBiuSmile/home-care-handover`。網站使用 GitHub Pages，登入與交班資料以 Supabase Auth + PostgreSQL / RLS 管理，不使用 Railway。

## 新功能：48 小時臨時交班室（A 自行建立，B 搜尋受邀個案）

- **主責 A** 已獲個案指派即可自己建立聊天室，直接邀請任何已啟用的居服員 **B**，不必等待居督或管理員為 B 做永久指派。
- **B** 登入後在工作台「受邀臨時交班」輸入個案姓名搜尋，**只看得到 A 邀請自己的房間**，不會取得整份個案資料權限。
- 新聊天室固定 **48 小時**，由 Supabase 伺服器時間判斷；到期即停止留言，原始對話保留。
- 到期後**只有具該案權限的居督或管理員**可以人工整理、一次發佈為最新「正式交班」，原始聊天不覆蓋。
- 舊版 24 小時聊天室保存原期限與紀錄；沒有提前關閉功能。
- 目前約每 15 秒更新對話（非推播），測試版尚未完成真實手機跨裝置驗證。

詳見 [48 小時自助臨時交班室使用說明](docs/TEMP_ROOM_GUIDE.md)。

## 新功能：個案照顧檔案與交班討論

已在既有個案頁新增三個標籤：

1. **照顧檔案**：已指派人員可提出照顧重點，須經居督／管理員審核後才列入已確認重點。原有管理員維護的固定重點繼續保留。
2. **交班討論**：同個案的已授權服務人員可以發問、回覆、補充；訊息保留作者及時間，可將討論先帶入照顧重點草稿等待審核。
3. **正式交班**：沿用原本的歷史交班、風險提醒、已讀確認與新增交班功能。

資料庫新增 `public.case_care_guide_items`、`public.case_discussion_messages`，均有 RLS；討論內容與提案不能由使用者任意覆寫或刪除。請參閱 [照顧檔案與討論使用說明](docs/CARE_COLLAB_GUIDE.md)。

**研究版提醒**：討論區約每 25 秒檢查新訊息（開啟討論分頁且瀏覽器可見時），不是緊急通知服務；完成正式資安與法規驗證前仍應只用虛構測試個案。

## 登入方式：員工手機與管理員 Email 分開

- 預設顯示「員工手機登入」；右上角設有獨立「管理員登入」切換。
- 管理員維持現有已驗證 Email 帳號，使用 Email＋密碼登入，無需另建帳號。
- 管理員忘記密碼時可點「忘記密碼／設定新的管理員密碼」，透過原信箱的 Supabase Auth 驗證連結，在網站自行設定新密碼。為安全起見，**不在 GitHub 或聊天紀錄儲存固定管理員密碼**。
- **密碼重設前置條件**：Supabase Auth 的 Redirect URLs 須加入 `https://biubiusmile.github.io/home-care-handover/`，且 Email 寄送可用。詳見 [登入與管理員密碼說明](docs/LOGIN_ADMIN_SETUP.md)。

## 最新版：管理員自訂員工密碼

- **員工帳號**：台灣手機門號（09xxxxxxxx）。
- **密碼**：由管理員在建立帳號時自行輸入，至少 10 字元、包含英文與數字；**新員工不需首次強制改密碼**。
- 管理員可從員工清單**重設居服員或居督密碼**；舊密碼不顯示、不允許查詢，重設只在伺服器端 Auth 執行。
- 管理員可刪除居服員／居督帳號，需輸入「刪除」二次確認；不能刪除自己或其他管理員，歷史交班內容及紀錄人姓名保留，操作紀錄儲存在受保護的稽核表。
- **密碼格式**：新增員工與管理員重設密碼都允許符合身分證格式的 10 字元英數字串，但因身分證字號容易被取得，**不建議將真實身分證字號作為登入密碼**。密碼仍須符合英數與長度規則，且不可包含員工手機號碼。
- **無自助註冊**：員工只能由管理員建立；建檔與密碼重設由受權限保護的 Supabase Edge Function 執行，沒有任何管理金鑰放在 GitHub Pages。
- 管理員可管理個案、指派服務人員及調整人員權限；居服員／居督只能查看獲指派個案。
- `demo.html` 使用虛構個案、瀏覽器本機儲存，不會寫入 Supabase。

## 安全與限制

管理員知道員工密碼可能產生身分冒用風險，應遵守內部密碼發放、存取及稽核規範。此版已部署但未經完整員工帳號端對端測試。**在完成完整資安與法規評估前，不要輸入真實個案或健康資訊。** 正式上線仍須補強 MFA、操作稽核、密碼重設通知、登入 session 風險處理、備份、換號及離職撤權流程。

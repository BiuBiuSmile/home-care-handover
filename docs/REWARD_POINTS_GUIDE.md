# 安護交班｜點數獎勵制度 v1（2026-11）

## 第一版規則

所有帳號的點數從 **0 點** 開始；不追溯舊照顧重點、交班或聊天室。系統只對新發生且完成審核的活動計點。

| 行為 | 核發條件 | 獲得點數 |
| --- | --- | --- |
| 新增自己個案的照顧重點 | 已獲指派的居服員／居督提交，經有權限的居督或管理員審核為「已確認」 | 提交者 +5 |
| 正式交班 | 已獲指派的員工新增「正式交班」，有權限的居督或管理員在「點數獎勵」頁確認完成；不可自己審核 | 提交者 +5 |
| 48 小時臨時交班室 | A 與 B **雙方各至少有一則 5 字以上的交班訊息**；交班室到期後，有權限的居督或管理員整理並發佈正式交班摘要 | A +5、B +5 |

不因「新增照顧重點但尚未審核」、單純建立聊天室、只傳送訊息、重複按審核或沒有實質參與而加點。每筆照顧重點／正式交班／交班室，每位符合條件者**最多只核發一次**。

正式交班須由居督或管理員按「確認完成・+5 點」，且審核後不可再重複操作。同一人不可審核自己提交的正式交班。

## 點數、獎品與申請

- **500 點**：星巴克星冰樂一杯。飲品尺寸、兌換方式與實際發放，由管理員協調確認。
- **600 點**：全聯 **NT$500 禮券**。
- 員工於「點數獎勵」頁查看自己可用點數、核點歷史、兌換門檻與申請紀錄。
- 達標後點「申請兌換」，系統**立即扣除所需點數**，建立「待發放」紀錄；並非按下申請就自動收到實體／電子票券。
- 管理員在同頁「兌換申請管理」點「確認已發放」才算發獎；若點「退回並返點」且填寫原因，已扣點數**完整返還**。
- 兌換不可超過可用點數；已處理申請不可重複處理。管理員可查看全部兌換申請，其餘使用者只看自己的。
- 初版不支援自動購買星巴克／全聯商品、電子券寄送、排隊發券、庫存管理或稅務申報；日後可再補充。

## 網站操作

1. 進入 [安護交班](https://biubiusmile.github.io/home-care-handover/) 並登入。
2. 點上方 **「點數獎勵」** 查看點數及兩項獎品。剛啟用且未完成任何審核時應為 **0 點**。
3. 要賺取照顧重點點數，進入有指派的個案 →「照顧檔案」→「＋新增重點」；等待有權限的居督或管理員「✓ 確認」。
4. 要賺正式交班點數，進入個案 →「正式交班」新增紀錄；居督或管理員之後在「點數獎勵 → 正式交班審核」確認內容並按「確認完成・+5 點」。
5. 48 小時聊天室的點數，需雙方實際留言並完成既有的「到期 → 居督／管理員人工整理、發佈」流程。
6. 累積足夠點數後，在「點數獎勵 → 獎品兌換」送出申請；由管理員人工核對並標註是否已發放。

## 安全與資料設計

- `public.reward_point_events`：只增不改的積分流水帳。點數餘額由所有正負紀錄加總，不信任瀏覽器提交的點數。
- `public.reward_catalog`：獎品品項與門檻，初始為星冰樂 500 點／全聯 500 元禮券 600 點；日後可調整。
- `public.reward_handover_reviews`：正式交班的審核結果，同筆交班只審一次。
- `public.reward_redemptions`：兌換申請／發放／退回紀錄與辦理人。
- 照顧重點使用現有「居督／管理員審核」資料庫流程；審核為 approved 時由觸發器自動記 +5。
- 正式交班審核、申請兌換、管理員確認發放／退回，使用 Supabase 的受限 RPC，**不能**由瀏覽器直接改寫流水帳。
- 48 小時聊天室在發佈正式整理後，由伺服器確認 A、B 是否雙方留言才發點。
- 所有獎勵相關資料表都啟用 RLS：點數及兌換紀錄員工只能查看自己的，管理員可以查閱；主管可依既有個案權限查核正式交班，不能自行發放禮品。
- 兌換交易使用使用者層級的資料庫交易鎖，避免同時申請兩項獎品造成超扣；審核授點有唯一來源限制，避免重複加點。
- 管理員必須使用獨立安全管道發放實際獎品。若涉及員工福利、所得或稅務，正式上線前由機構確認適用規範。

## 測試

已在正式 Supabase 資料庫的**交易回滾測試**中驗證：

- 經審核照顧重點 +5 點。
- 正式交班經審核 +5 點。
- 模擬 600 點先兌換 500 點，餘額不足時無法再兌換 600 點；退回後返還點數，再兌換 600 點成功且餘額歸零。
- 前端使用虛構資料測試一般員工獎品與 0 點畫面、可兌換門檻，以及管理員待審與獎品發放介面。
- **仍須用兩個真實居服員帳號，完整驗證「48 小時聊天室到期 → 發佈 → 雙方各 +5 點」的現場流程。**

未進行任何真實獎品採購或發放。所有交易測試資料已回滾。
